# Repository guidance

## Agent skills

### Issue tracker

Issues live in [GitHub Issues](https://github.com/pabumake/openyap/issues). See `docs/agents/issue-tracker.md` before claiming or changing an issue.

### Triage labels

The repository uses the standard engineering-skill triage vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

OpenYap uses a single domain context with `CONTEXT.md` at the repository root and ADRs under `docs/adr/`. See `docs/agents/domain.md`.
