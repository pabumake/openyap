# Security policy

## Supported versions

OpenYap is still in early development. Security fixes target the current release on the `main` branch.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/pabumake/openyap/security/advisories/new). Do not include microphone recordings, transcripts, credentials, or other personal data in a public issue.

Include the affected OpenYap version, macOS version, reproduction steps, and the security impact. A minimal test case is useful when it does not contain private data.
