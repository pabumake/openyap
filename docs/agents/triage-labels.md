# Triage labels

The engineering skills use five canonical triage roles. GitHub issues record the corresponding label.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue is waiting for information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | An AFK agent can implement the fully specified issue. |
| `ready-for-human` | `ready-for-human` | A human must implement or complete the issue. |
| `wontfix` | `wontfix` | The maintainers will not act on the issue. |

When a skill names a triage role, apply the matching GitHub label from this table.
